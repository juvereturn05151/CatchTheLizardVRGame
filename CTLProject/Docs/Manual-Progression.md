# Manual progression

The implemented order is **stationary toy tutorial → one moving wind-up toy → three real lizards**. Start still opens Level Selection. Music and SFX use the existing subsystems.

Tutorial keeps the instructor welcome and pickup/container lesson. Successful storage completes the objective immediately and displays: “Training complete! Open the door and leave to begin your first assignment.” There is no broom/spray or broom lesson. The player opens the handle and exits before the shared completion panel offers Next Mission (Level 1) and Return to Menu.

Level 1 reuses BP_Lizard movement, broom herding, grabbing, and bottle storage through the separate BP_MovingToyLizard child. Pink plastic and a gold wind-up key identify it as artificial. Its capture target is one. The instructor’s requested introduction must be acknowledged before the toy moves or can be caught. Storage changes the objective to opening the door and leaving. The requested closing dialogue appears directly on the completion panel, before Next Mission loads Level 2.

Level 2 uses the existing real BP_Lizard actors, target three, broom and the existing unlimited-capacity collection bottle. No spray is placed at startup. The requested introduction must be acknowledged before the challenge and emergency clock start. The physical emergency button dispenses a single ordinary grabbable BP_Spray after 120 active gameplay seconds. Pausing freezes that clock. The button never stuns lizards; only the existing spray exposure/stun system does that. Locked presses and failed spawns leave assistance false and allow retry. Successful spawning latches assistance and prevents another dispense for that attempt.

All exits start closed. Put either controller at the reachable handle and make a fresh index-trigger press. The leaf rotates around an editable hinge; its blocking collision follows it. The saved outdoor landing and head-position exit zone remain beyond the doorway. A native check in BP_XRPawn’s existing TryTeleport rejects destinations across a closed exit, including arcs that pass over it. Normal teleport navigation remains continuous through the doorway once open. Hands and objects cannot complete a stage. Opening a door cannot complete it. Leaving early shows the remaining objective; return inside and exit after satisfying the objective.

Only Level 2 receives stars, calculated once on completion after the player exits: three filled stars without successful dispensing; one filled and two empty stars with successful dispensing. The encouraging result text and actual star images appear on the shared VR completion widget. Restarting/reloading the map resets progress, time, assistance, dispensing, and awarded stars.

## Designer controls

- **Emergency:** `/Game/CatchTheLizard/Missions/BP_EmergencySprayButton`, placed as **Emergency Spray Dispenser** in `Map_CatchTheLizard_Level2`. Edit **Unlock Delay** (120 seconds), **Spray Class**, countdown/ready/dispensed text, button mesh/material and **PressInteraction → Reach Radius**. Move/rotate the **SpraySpawnPoint** scene component to edit the complete relative spawn transform. Move the nearby **Emergency Spray Shelf** with it as appropriate. Failed collision-blocked spawns do not consume assistance.
- **Door:** `/Game/CatchTheLizard/Missions/BP_ExitDoor`, placed as **Training Exit** or **House Exit**. Edit **Open Angle**, **Open Speed**, **Hinge**, **DoorMesh**, **Handle**, **HandleInteraction → Reach Radius**, signs and **OutdoorZone**. The hinge always starts closed; objective readiness only changes signage. Keep the trigger beyond the threshold. Doorway is 198 cm wide, with the handle 105 cm above floor. Use the visible leaf’s blocking collision when substituting meshes.
- **Targets and destinations:** select **Mission Director** in Level 1/2 or **Tutorial Exit Mission** in the tutorial. Edit **Capture Target**, **Mission Lizards**, **Containers**, **Mission Tools**, **Exit Door**, **Next Mission**, **Main Menu** and objective text. Keep the target within the number of assigned lizards. Tutorial uses **bTutorial**; only Level 2 enables **bEmergencyRating**. Existing collection managers retain **bRequireExit**.
- **Dialogue:** the placed mission director’s **Introduction** and **Debrief** fields are editable. Tutorial welcome/practice text stays in `BP_TrainingDirector`. All reuse `WBP_TutorialDialogue` and `BP_TrainingInstructor`. Introduction acknowledgement enables the same native mission state; there is no second mission manager.
- **UI:** `/Game/CatchTheLizard/Missions/WBP_MissionComplete` contains editable **DebriefText**, **RatingText**, **Star1/2/3**, Next Mission and Return to Menu. **FilledStar/EmptyStar** reference the textures in `Missions/UI`. The original PNG sources are in `SourceArt/MissionUI`. The editable M_VRPanelAlwaysVisible material keeps the completion panel readable when a wall or the opened door is behind it; geometry ignores the existing 3DWidget pointer channel. Existing objective and tutorial dialogue widget layouts remain editable. Panel draw size/scale and Completion Panel Distance are on the director.
- **Level Selection:** names and maps are in `/Game/CatchTheLizard/Tutorial/DA_LevelList`; subtitle/layout is in `WBP_LevelSelection`.

## Implementation and authoring

Native state/flow lives in `MissionFlow`, `TrainingDirector`, `LizardGameplayActor`, `EmergencySprayButton`, `PhysicalPressInteraction`, `TutorialWidgets` and `VRPanelInteractor`. Spray spawn restrictions apply only to maps containing this mission director; unrelated worlds retain their original tools. Spawned emergency spray joins the director’s existing completion cleanup list. Tutorial retires its pointer interactor at storage so it cannot compete with the completion panel.

Saved maps: `Map_TrainingFacility`, `Map_CatchTheLizard`, `Map_CatchTheLizard_Level2`. Main changed/new assets: BP_ExitDoor, BP_MissionDirector, BP_EmergencySprayButton, BP_MovingToyLizard, WBP_MissionComplete, tutorial dialogue/director/catalog/selection, star textures, materials and BP_XRPawn’s teleport gate.

`Scripts/Editor/setup_manual_progression.py` records the assets/tutorial/level1/level2/catalog authoring phases; `setup_exit_teleport_guard.py` records the scoped native gate insertion. Runtime has no Python dependency. Existing work in the checkout is preserved.

Build/check evidence is recorded under `Saved/MissionCheckpoint/ManualFlow-*`. Quest 2 playtesting remains necessary for controller reach, stereo readability, room-scale passage, teleport feel and the audio mix. No Android packaging or extensive automated test suite is part of this update.
